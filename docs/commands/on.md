# tacet on

Turns a feature on for this project.

```sh
tacet on audio
```

The switch is saved in `.tacet/config.yaml`. [`tacet undo`](undo.md) reverts it.

Features: [convert](../features/convert.md), [guard](../features/guard.md), [handoff](../features/handoff.md), [audio](../features/audio.md), [map](../features/map.md), [skills](../features/skills.md), [budget](../features/budget.md), [bigoutput](../features/bigoutput.md), [feedback](../features/feedback.md), [testgate](../features/testgate.md), [subagents](../features/subagents.md).

An unknown name prints the list of features.
