# Apache License 2.0 notices

The `tacet` binary links Go modules released under the Apache License
2.0. That license asks that its text and a module's NOTICE file travel
with any binary built from it. `LICENSE-Apache-2.0` is the license and
`NOTICE` holds each NOTICE file, unchanged, under the module path and
version from `go.mod`. [THIRD_PARTY/README.md](../README.md) lists every
such module.
