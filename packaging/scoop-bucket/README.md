<h1 align="center">scoop-bucket</h1>

<p align="center"><b>Scoop manifests for Rhythm Shahriar's tools, updated by each release.</b></p>

```powershell
scoop bucket add rhythmshahriar https://github.com/RhythmShahriar/scoop-bucket
scoop install tacet
```

| App | What it is |
|---|---|
| [tacet](https://github.com/RhythmShahriar/tacet) | Makes Claude Code use fewer tokens on any project |

Update with `scoop update tacet`; remove with `scoop uninstall tacet`. Each release of a tool writes its file under `bucket/`; don't edit them by hand.
