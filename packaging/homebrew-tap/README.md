<h1 align="center">homebrew-tap</h1>

<p align="center"><b>Homebrew casks for Rhythm Shahriar's tools, updated by each release.</b></p>

```sh
brew install rhythmshahriar/tap/tacet
```

| Cask | What it is |
|---|---|
| [tacet](https://github.com/RhythmShahriar/tacet) | Makes Claude Code use fewer tokens on any project |

Update with `brew upgrade --cask tacet`; remove with `brew uninstall --cask tacet`. Each release of a tool writes its file under `Casks/`; don't edit them by hand.
