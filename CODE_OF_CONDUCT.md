# Code of conduct

tacet follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith and keep discussion about the work.

## Enforcement

Report unacceptable behavior to me@rhy.io. Every report is reviewed and kept confidential. The
maintainer may remove, edit or reject comments, commits, code, issues and other contributions
that don't follow this code and may ban anyone from the project for behavior that is
inappropriate, threatening, offensive or harmful.

The full text, including the enforcement guidelines, is at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
